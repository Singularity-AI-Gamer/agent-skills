# 45 秒分镜结构与多平台发布手册

## 一、11 镜标准 45 秒拉新分镜模板

适用帧率 `12 fps`（纸艺定格）或 `24 fps`（平滑 UI 动效），总长控制在 `42s–47s`（实际时长由连贯口播的气口时间戳决定）：

| 镜号 | 参考时长 | 构图模式 | 画面核心动作 | 口播功能 |
|---|---|---|---|---|
| S01 | ~3.5s | 痛点隐喻舞台 | 旧方案崩溃场景（如聊天气泡挤爆/报错弹窗裂开 + 红叉砸下） | 1 句直白反问抛痛点 |
| S02 | ~4.2s | **满幅全屏实机** | 撕纸/推拉切入完整软件主界面（占宽 88%），角落贴核心背书徽章 | 亮出产品形态 + 背书 + 名字 |
| S03 | ~4.0s | **满幅全屏实机** | 全屏窗口上用红框 + 箭头依次点亮左/中/右三大核心功能区 | 一句话讲清界面架构与工作方式 |
| S04 | ~4.2s | **全屏底图 + 局部弹出** | 痛点 1 定位红框 → 弹出对应功能高清特写卡 + 绿勾确认 | 痛点 1 → 核心功能 1 解决方式 |
| S05 | ~4.2s | **全屏底图 + 局部弹出** | 痛点 2 定位红框 → 弹出对应功能高清特写卡 + 状态流转动画 | 痛点 2 → 核心功能 2 解决方式 |
| S06 | ~4.2s | **全屏底图 + 局部弹出** | 痛点 3 定位红框 → 弹出对应功能高清特写卡 + 逐项核对动画 | 痛点 3 → 核心功能 3 解决方式 |
| S07 | ~4.5s | **全屏底图 + 局部弹出** | 痛点 4 定位红框 → 弹出核心对比/操作特写卡 + 采纳/保留标签 | 痛点 4 → 核心功能 4 解决方式 |
| S08 | ~4.0s | **全屏底图 + 局部弹出** | 展示模型/扩展/兼容性设置全屏 → 弹出配置卡片 + 亮点贴纸 | 加分王炸 1（如本地离线/多端兼容） |
| S09 | ~3.8s | **全屏底图 + 局部弹出** | 展示导入/自动化/隐私保障界面 → 弹出拆解卡或安全盾牌 | 加分王炸 2（如数据安全/一键迁移） |
| S10 | ~3.8s | 价值收束舞台 | 碎片卡片向中心汇合，装订/融合为完整成果形态 | 总结用户收益（效率/秩序/掌控感） |
| S11 | ~4.5s | **全屏衬底 + 搜索落版** | 底层微虚化全屏主界面，居中弹出超大搜索框 `🔍 搜索：<BrandSearchTerm>` | 明确开源/免费属性与搜索引导 |

### 节奏防呆约束
- 单镜最短不少于 **`2.8s`**（避免闪屏），最长不超过 **`5.5s`**（避免拖沓）。
- 口播每句中文控制在 **12–22 字**，底部双语字幕中文不超过 **16 字/行**，英文不超过 **52 字符/行**。

## 三、各平台文案策略与防限流红线

### 1. 平台差异化话术重点
- **抖音**：前 1 行直戳痛点 + 场景共鸣，条目用 `✅` 清单，适合口语化短句；引导检索词放在文末或评论区首条置顶。
- **小红书**：标题 `<= 20` 字，突出“不崩/省事/效率工具”；正文口语分享感，分段短小配合序号表情，结尾抛开放问题引导评论互动。
- **知乎**：理性工程拆解视角，先讲传统工作流的底层结构缺陷，再分点说明本软件的机制解法，最后给出检索关键词。
- **B站**：可附简短 `00:00` 时间轴导览与开源/技术亮点，结尾自然引导三连与评论区反馈，适合科技/软件应用分区。

### 2. 防限流敏感词替换表

| 高风险限流行为 / 词汇 | 原因 | 安全替换写法 |
|---|---|---|
| 正文放 `https://github.com/...` 等外链 | 站外导流降权或拦截 | 仅写项目/软件检索名 `搜索：<BrandSearchTerm>` |
| `私信领` / `扣 1 发安装包` / `加群` | 诱导互动与私域导流 | `感兴趣可以搜项目名了解体验` |
| `最强` / `第一` / `吊打` / `神器` / `白嫖` / `免费送` | 违禁广告极限词 | `开源工具` / `免费开源` / `工作台` / `提升效率` |
| `无审查` / `破限制` / 敏感题材直白词 | 内容安全审核触发 | `支持本地模型离线运行` / `保护本地隐私` |
| 含 AI 配音/图像却不勾选声明 | 易被机器识别为未标注合成内容 | 发布时主动勾选平台“AI 辅助创作”声明 |

# TTS 连贯配音与全局节拍混音规范

## 一、TTS 连续配音生成规范

### 1. 严禁踩的 3 个坑
- **坑 1：复用旧音频缓存**：换稿或换音色前，必须先清空 `voice/` 下的成品 `.wav` 与候选 take 目录。
- **坑 2：使用个人克隆音色**：绝不写入个人克隆 voice ID（`voice_*`）；公开或通用软件宣传片必须使用官方标准内置音色，并写断言校验。
- **坑 3：逐句拆开生成 + 强行 `atempo` 变速**：按句单独调用 TTS 会导致每句基频、音量和语速不一致，再强行缩放时长会产生明显的机器切割感。

### 2. 标准生成方法（以 Gemini TTS 为例）
- 将环境变量占位符写入示例（实际运行时读取环境变量）：`os.environ["TTS_API_KEY"]`。
- **官方内置推荐音色**：`Puck`（清爽阳光青年男声）、`Aoede`（清晰干练女声）、`Fenrir`（沉稳质感男声）。
- **连贯输入**：把所有镜头口播台词按 `\n` 拼为一次（或 2–3 个大意群）传入 TTS，`style` 提示词明确要求：
  > `"年轻效率软件测评博主，清亮通透，口语化自然连读。句间留约 0.15 秒自然换气，不拖腔、无播音腔、关键词清晰重读，总时长控制在 43 秒左右。"`
- **Audio-First 切镜**：使用 [../scripts/derive_shot_frames.py](../scripts/derive_shot_frames.py) 扫描整条 `.wav` 的短时 RMS 能量谷底，将自然停顿对齐到 `N` 个镜头边界，直接输出帧数 `frame_boundaries`（允许用片尾静止/落版延长 0.5–1.2s 来凑整目标时长，**绝不扭曲前面口播的语速**）。

## 二、全局连续节拍编曲规范（根治错拍与“没音乐”）

### 1. 全局单一节拍网格
- 设定固定速度 `BPM = 124`（`beat = 60 / BPM ≈ 0.4839s`），全片长度 `T`（约 `45s`）内只有**唯一一个主循环**：
  ```python
  for beat_idx in range(int(np.ceil(T / beat))):
      b = beat_idx * beat
      pos = beat_idx % 4
      chord = chords[(beat_idx // 4) % len(chords)]
      ...
  ```
- **绝对禁止**：
  - 在 `for shot in shots:` 循环里用 `np.arange(s, e, beat)` 重置鼓点；
  - 插入随机偏拍底鼓（如 `b + beat * 0.75`）；
  - 在盖章/切换视觉节点处额外叠加底鼓（`stamp` 只能用轻巧纸拍声或高频木琴叮咚，绝不碰低频 Kick）。

### 2. 饱满立体声编曲配方（拒绝干瘪单音 & 禁止中频挖空）
- **鼓组（居中略微展开）**：
  - `Kick`（1、3 拍）：`47 Hz` 基频 + 快速下扫瞬态 + 轻微高频击槌，衰减干净（`exp(-15*t)`）；
  - `Rim / Clap`（2、4 拍）：`1050–6800 Hz` 带通双层拍击 + 轻微 `870 Hz` 木腔共鸣；
  - `Hi-Hat`（16 分音符，1 拍 4 下）：`6500–12800 Hz` 强弱交替（`[0.25, 0.12, 0.185, 0.10]`），微调左右声像增加律动。
- **和声与旋律（左右声像让出正中人声位，但不挖空频率）**：
  - **立体声电钢琴铺底（`pan = ±0.38`）**：流行大调进行（如 `D - A - Bm - G`），1、3 拍轻柔分解柱式和弦；
  - **明快八分音符 Riff（`pan = ±0.45`）**：木琴/拨弦吉他音色，在每拍前半拍与后半拍交错弹跳；
  - **Bassline（`pan = -0.04`）**：跟随和弦根音走低八度厚实线条。
- **严禁使用 `500–2800 Hz` `bandstop` 滤波器**！正中人声与左右摆开的乐器靠声像（Mid/Side）和侧链衰减分离，挖空中频会导致外放时 BGM 彻底消失。

## 三、人声侧链闪避与响度校验标准

1. **人声归一化**：`80 Hz` 高通滤波去除喷麦低频，EBU R128 响度归一化至 **`-14.0 LUFS`**，单声道居中放置。
2. **动态侧链包络**：以 `10 ms` 窗口提取人声短时 RMS 包络，做平滑扩张（`maximum_filter1d` + `gaussian_filter1d`），生成 `duck ∈ [0, 1]` 曲线：
   - 说话激活时：压低 BGM 至目标背景响度（约 **`-21.5 LUFS`**）；
   - 句间气口/片头片尾无人声时：平滑抬升 BGM 至约 **`-16.0 LUFS`**。
3. **强制代码校验门禁**：
   - 运行 [../scripts/check_audio_mix.py](../scripts/check_audio_mix.py) 检测人声激活段内 `BGM_RMS_dB - Speech_RMS_dB`；
   - 必须严格落在 **`[-8.5, -7.0] dB`** 区间（外放手机/电脑都能清晰听见明快鼓点与和弦，同时人声字字分明），超出即报错阻断打包。
4. **防削波软限幅**：合成后对超过 `0.82` 的瞬态峰值做平滑 `tanh` 软限幅，防止输出爆音。

# 视觉合成、全屏与局部弹出规范

## 一、实机截图采集规范

1. **统一窗口分辨率**：录制或截图软件全窗口时固定为 **`1440x900`** 或 **`1920x1080`**（16:10 或 16:9），保证 UI 缩放一致、字迹锐利。
2. **必须有真实业务数据**：打开真实示例工程截图，避免空欢迎页或“测试数据 123”占位文字。
3. **只采全屏图，不在采集阶段裁小**：全部保存为完整窗口图（如 `ui/ui_home.png`、`ui/ui_feature1.png`），放大特写由合成脚本按像素框实时裁剪渲染，确保底层全屏定位与上层特写 100% 同源对齐。

---

## 二、画布尺寸与三段接力动画曲线

- 画布：`1280x720`，帧率：`12 fps`（定格纸艺风）或 `24 fps`（轻量动效）。
- 缓动函数：三次平滑插值 `ease(x) = x*x*(3 - 2*x)`（`x` 钳位在 `[0, 1]`）。
- **单镜三段接力时间占比 `t ∈ [0, 1]`**（彻底避免“前 1 秒动完、后面 4 秒静止”）：
  - `a = phase(t, 0.00, 0.28)`：转场入场 + 红框绘线定位（`0.00–0.26` 渐进描边）。
  - `m = phase(t, 0.28, 0.74)`：核心演出（特写卡片由小到大弹出、或纸片移动/翻转/对比）。
  - `z = phase(t, 0.70, 0.96)`：强反馈收尾（绿色确认印章砸下带微弹性缩放 + 结果标签滑入 + 轻微呼吸微动）。
- 纸艺微颤（仅 12 fps 定格风格可选）：`j = math.sin(frame_idx * 1.9) * 1.2` px，模拟真实逐格摆拍的轻微手工呼吸感，幅度不超过 `1.5 px`。

## 三、双层构图精确布局参数（1280x720 基准）

### 模式 A：满幅全屏窗口构图（S02 / S03 / S11）
- 完整窗口缩放宽度 `w = 1108..1128`（占 `1280` 画布宽度的 `86.5%–88%`），水平居中 `x = (1280 - w) // 2`，顶部留白 `y = 3..6 px`。
- 纸艺卡纸外框：向窗口四周仅扩展 `6–7 px` 奶油色底边（`#fff0ce`）+ 右下偏移 `4–5 px` 投影，不挤占屏幕面积。
- 徽章与角标：以纸艺贴纸形式叠放在窗口左上/右上/左下角边缘；结尾搜索卡 `S11` 将底层全屏窗做 `15%` 柔和虚化与 `14%` 压暗，正中叠加高对比搜索框（宽约 `880 px`，高约 `130 px`）。

### 模式 B：全屏底图定位 + 弹出高清局部特写卡（功能演示镜）
1. **底层全屏锚点**：`w = 1120 px` 居中摆放。当 `t > 0.32` 弹出特写卡时，底层全屏图平滑压暗至 `brightness = 0.82`（`dim = 0.18 * u`），保留完整界面空间感同时突出前景。
2. **动态红框与箭头定位**：
   - 将原图目标区域 `(bx0, by0, bx1, by1)` 按 `s = w / src_width` 映射到画布坐标 `rect`；
   - 按周长比例 `q = phase(t, 0, 0.26)` 顺时针一笔一划画出 `5px` 红色高亮框（`#be4435`），并在左侧跟随摆动纸艺箭头。
3. **高清局部特写卡弹出**：
   - 特写卡最终宽度 `cw ≈ 740..800 px`（占屏宽 `58%–63%`），插值尺寸 `cw_t = cw * (0.15 + 0.85 * u)`；
   - 位置从定位框中心 `(ax, ay)` 平滑飞向**对侧或错位区域**（保证原来的红框定位点仍部分可见，让观众能对应“它从哪来的”）；
   - 底部上限限制 `top <= 590 - h`，避免压住底部双语字幕条。
4. **引导线与多层投影**：
   - 用两条双层线条（外描 `6px` 奶油白 + 内芯 `2px` 砖红，起点画 `5px` 金色圆钉）连接红框对角与特写卡对角；
   - 特写卡下方叠加 `GaussianBlur(9)` 半透明深褐阴影（`rgba(30, 25, 20, 148)`），再贴剪纸奶油边框与高清局部截图。

## 四、底部双语字幕与转场规则

- **底部双语字幕条**：`y = 648 px`，高 `69 px`，宽度自适应文案并居中；**中文在上（`25px` 粗体）、英文在下（`17px` 常规体）**，严格避让特写卡片底边与结果标签。
- **转场**：在每镜末尾 `t > 0.95`（最后 1–2 帧）右侧边缘可加快速斜切锯齿撕纸边缘预览条，配合音频轻纸声，强化定格翻页手感。
